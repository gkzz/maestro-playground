# Maestro iOS Issue #3495 Investigation

## Environment

The investigation is run from GitHub Actions using `.github/workflows/e2e.yml` on `macos-26`.

Default workflow inputs:

- Maestro versions: `2.3.0` and `2.8.0`
- Xcode: `26.3`
- Runtime: `iOS 26.2`
- Device: `iPhone 17 Pro`
- Iterations per version: `20`
- Iteration timeout: `300` seconds
- Safari URL: `https://docs.maestro.dev/extra-materials?ask=maestro-ios-3495`
- Default flow: `.maestro/investigations/ios_3495_safari_webview_churn.yml`

The workflow records `sw_vers`, `xcodebuild -version`, `xcode-select -p`, `xcrun simctl list`, available runtimes, available device types, runner image metadata, and `maestro --version` for each tested CLI version.

## Reproduction Steps

1. Open the `E2E` GitHub Actions workflow.
2. Run it with the default workflow dispatch inputs.
3. Use `iterations=20` for the first comparison. Increase to `50` if the initial run is inconclusive and runner time is acceptable.
4. Compare the uploaded artifact directories under `artifacts/investigations/maestro-ios-3495/maestro-<version>/run-NNN/`.
